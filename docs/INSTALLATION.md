# Instalação

1. Clonar `https://github.com/mxcapellani/IAIRON-Ultimate.git` ou baixar o pacote de arquivos do GitHub.
2. No projeto do agente compatível, copiar `.agents/skills/iairon-ultimate/` para o local de descoberta aceito. Preservar referências e exemplos relativos ao SKILL.md.
3. Pedir explicitamente: “Use iairon-ultimate para criar um retrato do meu avatar”. Se a interface não descobrir a pasta, seguir o método de importação do host. Não há instalação automática só por conexão ao GitHub.
4. Disponibilizar a referência de identidade ao agente se quiser análise e ao gerador se o prompt depender dela. Uma imagem na conversa não é automaticamente enviada a plataformas externas.
5. Validar com os comandos do README antes de atualizar uma instalação existente.

Python e PyYAML só são necessários para as verificações do repositório. A Skill é textual, sem serviço em execução, credenciais ou cobrança própria. Os custos e permissões dos geradores pertencem às respectivas plataformas. Não copiar chaves em arquivos de exemplo.
